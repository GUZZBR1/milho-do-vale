# Milho do Vale

Landing page estática do Milho do Vale, produção local de milho verde em São José dos Campos — SP.

## Estrutura

- `index.html` — estrutura semântica da página.
- `styles.css` — identidade visual, responsividade e animações.
- `script.js` — menu mobile, animações de entrada e CTA do WhatsApp.
- `assets/corn.svg` — ilustração vetorial da espiga.

## Executar localmente

Abra `index.html` no navegador. Para configurar o botão de WhatsApp, edite `WHATSAPP_NUMBER` no início de `script.js` usando o formato internacional sem `+`, espaços ou pontuação.
